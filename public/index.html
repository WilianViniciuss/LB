    Como usar

    Fluxo de extração e lançamento em quatro passos.

    1. Links: cole os links dos boletos (um por linha) ou envie um .txt. Linhas iniciadas com # são ignoradas.
    2. Extração: clique em Iniciar Extração. Ela roda em segundo plano; use Pausar ou Parar quando quiser.
    3. Navegador: clique em Abrir Navegador, faça login no Via Imob e deixe a tela Manutenção encargo visível na aba ativa.
    4. Condomínios: após a extração, cada link fica salvo no seu condomínio. Na tela Condomínios use Extrair ou Usar links para repetir no mês seguinte.
    5. Lançamento: Iniciar Lançamento preenche o próximo boleto pronto. Ao concluir, ele é marcado como lançado e vai para o Histórico. Confira o total e grave no Via Imob. Se não gravar, use Desfazer no Histórico.
    6. Avisos do Via Imob: após o código identificador, o código de barras e cada ocorrência, o app confere se apareceu um aviso (ex.: código não encontrado, já lançado). Se aparecer no código ou nas barras, ele tira uma foto, fecha o aviso, marca o boleto como Erro e segue para o próximo. Se for numa ocorrência, ele fecha o aviso e para, para você conferir a tela.

    Tudo fica salvo no banco local dados/boletopro.db, com cópia de segurança diária em dados/backup/. Boleto repetido na extração (mesma linha digitável) é ignorado e registrado em Duplicidades; um boleto já lançado nunca é lançado de novo.

    No Histórico dá para excluir boletos selecionados ou limpar tudo. Boleto excluído do Histórico perde a proteção contra lançamento duplo.

    Boletos com problema (soma divergente, dados ausentes ou ocorrência sem mapeamento) não são lançados. Ajuste mapaOcorrencias no config.json quando necessário.
